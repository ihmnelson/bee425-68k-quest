# bee425-68k-quest has moved

This repository used to be **68K Quest**, a study site for 68000 assembly (BEE 425). It has been merged with a new Z80 study site into a single site, **BEE 425 Quest**:

- Site: https://ihmnelson.github.io/bee425/
- Code: https://github.com/ihmnelson/bee425

The repository was renamed from `bee425-68k-quest` to `bee425`. GitHub redirects the old *repository* address automatically, but it does not redirect old *GitHub Pages* addresses, so this small repository exists only to keep the old site link working. Opening https://ihmnelson.github.io/bee425-68k-quest/ now forwards you to the new site, and old deep links such as `.../bee425-68k-quest/#/cards` land on the matching 68000 page.

Your study progress and saved sandbox projects are not lost: they are stored in your browser, which treats both addresses as the same site, and the new site migrates them the first time you open it. If anything looks missing, use *Progress, Restore from backup* with a backup file made on the old site (those still work).

There is nothing else here and no need to update bookmarks beyond the new address above.
